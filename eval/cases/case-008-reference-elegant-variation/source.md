PostgreSQL is an open-source relational database management system. The database engine supports ACID transactions, complex queries, and extensible data types. The RDBMS was originally developed at the University of California, Berkeley, as a successor to the Ingres project. The database system first appeared in 1996 under its current name.

The software platform provides several indexing methods including B-tree, hash, GiST, and GIN. The data management solution supports both SQL and JSON query interfaces. The storage engine uses multiversion concurrency control (MVCC) to handle concurrent access without read locks.

The relational engine offers built-in replication capabilities for high availability. The open-source platform supports logical and streaming replication modes. The database technology can be extended with custom functions written in PL/pgSQL, Python, Perl, and other languages.

PostgreSQL serves as the foundation for several derived products. The enterprise solution has garnered significant adoption in financial services and government sectors. The data platform competes with other relational databases including MySQL and Oracle Database.
