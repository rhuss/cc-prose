PostgreSQL is an open-source relational database. It supports ACID transactions, complex queries, and extensible data types. Originally developed at UC Berkeley as a successor to Ingres, it first appeared under the PostgreSQL name in 1996.

PostgreSQL provides several indexing methods including B-tree, hash, GiST, and GIN. It supports both SQL and JSON query interfaces and uses multiversion concurrency control (MVCC) to handle concurrent access without read locks.

PostgreSQL has built-in replication for high availability, supporting both logical and streaming modes. It can be extended with custom functions written in PL/pgSQL, Python, Perl, and other languages.

Several derived products build on PostgreSQL. It is widely used in financial services and government, and competes with MySQL and Oracle Database.
