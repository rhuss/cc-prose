So you want to set up a home lab. Good news: you probably already have most of what you need.

Any old desktop or laptop works as a starter server. I ran my first setup on a ThinkPad with a cracked screen and 8 gigs of RAM. It doesn't need to be fancy.

For a first project, try a media server. Jellyfin is free and open source; Plex has a slicker interface but locks some features behind a subscription. Either one takes about 20 minutes to set up. After that, home automation or self-hosted cloud storage are solid next steps, but don't try to do everything at once.

Used enterprise hardware on eBay keeps costs reasonable. Dell PowerEdge R720s go for $100-200 and handle most homelab workloads, though they're loud enough to annoy anyone sleeping nearby. Factor in electricity costs too, because older servers are not exactly power-sipping.
