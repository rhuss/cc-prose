AI coding assistants are everywhere now. GitHub reports over 1.8 million paying Copilot users. Every major IDE has at least one AI plugin. The question stopped being "should we use these?" sometime in 2024.

They do speed things up, sometimes. Boilerplate, test scaffolding, config files, the stuff nobody wanted to write by hand anyway. But I keep running into the same problem: the code looks right, compiles fine, and does the wrong thing. You stop reading carefully because the suggestion seems plausible, and that is exactly when it burns you.

The real issue is not whether AI can write code. It can, sort of. The issue is whether your team reviews AI-generated code with the same rigor as human-written code. Most don't. A 2024 Uplevel study found no measurable difference in pull-request throughput between teams using AI assistants and those without. Faster first drafts do not mean faster shipping if review and debugging eat the difference.

If you are adopting these tools, skip the cultural manifestos. Start with tests. If you do not have tests, you cannot tell whether the suggestion is correct. That is the whole story.
